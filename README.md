# Git & GitHub Assignment

This project demonstrates the basics of version control using Git and GitHub.
It covers repository setup, branching, merging, and deployment workflows
as part of the DevOps Module 2 assignment.

## What I Learned
- How to initialize a Git repository and make commits
- How to create branches and work on features separately
- How to push code to GitHub and create Pull Requests
- How to merge branches and keep local and remote repos in sync
